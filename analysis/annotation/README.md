# Independent annotation (2 radiologists + 1 LLM-assisted annotator)

- Task A (n=100): re-audit of the extractor-based gold labels on the same stratified sealed cases as the author audit; 1-5 scales for coverage / contradiction / spuriousness.
- Task B (n=120): persistence adjudication of forgiven omission-type false positives (100 items sampled from the union of three arms) with 20 blinded attention controls; 1-5 persistence scale + two exception flags (target-actually-mentions; prior-label-unsupported). Item grouping in `taskB_item_mapping.json`.
- `*_llm_assisted_annotator.json`: this annotator disclosed using an LLM (gpt-5.6-sol) during annotation and is excluded from the primary two-radiologist statistics.
- **Judgment-basis debriefing (important for reanalysis):** the radiologists reported that Task-B scores of 1-2 ("likely resolved") were grounded chiefly in the expectation that a persisting abnormality would have been restated by the reporting radiologist (i.e., the reporting convention itself), whereas 4-5 reflected clinical reasoning; they considered reliable persistence adjudication to require the underlying images, which MIMIC-IV does not include. Scores of 1-2 should therefore NOT be read as image-level evidence of resolution.
- Notes fields were stripped before release (they paraphrase MIMIC-derived report content); full annotations are available under the MIMIC-IV DUA.
